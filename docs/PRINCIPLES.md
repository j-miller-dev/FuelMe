# Principle notes (M10e)

One short note per idea, in YOUR words, in a vault folder such as `Fuel/Principles/`. Import them on the **My notes** page (Progress > My notes). FUEL only reads; it never writes to the vault.

```markdown
---
id: sleep-first            # optional; defaults to the file name. Re-imports update by this id.
source: Book or mentor     # shown on the card and cited by the coach
tags: [recovery, sleep]    # recovery/rest/sleep, intensity/training/effort/technique, nutrition/food/eating drive the Today card
grade: strong              # strong | rule_of_thumb | opinion   (default opinion)
stance: follow             # follow | context | ignore          (default context; you can override it in the app)
---
# Sleep before volume
Progress is decided in recovery, so protect sleep first.
```

Rules: max 1200 characters (a longer note is rejected, so book passages cannot be pasted in by accident); `[[wikilinks]]` become plain text; "Archive missing notes" only when you pick your whole folder. The coach (`search_principles`) never sees `ignore` notes. Numbers inside a note are the author's, not your targets.

Persona: `resources/coach/trainer-persona.md` is an ORIGINAL character (logic first, calm intensity, mechanism-minded). Edit the file to taste; `FUEL_COACH_PERSONA=neutral` turns it off. It sets style only: grounding, no-medical-advice and no-shaming rules still win, and it never claims to be a real person or invents quotes.
